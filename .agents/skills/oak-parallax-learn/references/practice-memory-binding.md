# Practice memory binding

Parallax skills are procedures, not memory stores. Emit a proposed handoff to the host Practice when
its surfaces exist; otherwise emit a portable memory-intent record for the host or user to place.
Named destinations are routing information, not write authority. Persist only when the user or an
explicit host workflow grants that authority, and record the authority and resulting artifact.

| Substance | Practice destination |
| --- | --- |
| Fresh surprise, correction, or anomalous outcome | `.agent/memory/active/napkin.md` |
| Refined cross-session lesson | `.agent/memory/active/distilled.md` |
| Grounded recurring instance | `.agent/memory/active/patterns/` |
| Live inquiry, monitoring, or next-safe-step state | `.agent/memory/operational/` |
| Stable host contract or routing vocabulary | `.agent/memory/executive/` |
| Settled project decision | Permanent documentation or ADR |
| Portable Practice governance | PDR through the host's consolidation process |
| Stable behavioural improvement | Canonical skill, rule, or directive after evaluation |

Follow the host's actual Practice indexes and placement contracts; this table is a routing default,
not authority to invent or mutate files. Preserve the sequence `capture -> distil -> graduate ->
enforce`. Never write volatile work state into a skill body or copy a session transcript into
permanent doctrine. A proposal remains `not-written` until authorised persistence actually occurs.

If the host uses immutable memory events with rendered projections, append a new event with typed
`refines`, `supersedes`, `duplicate-of`, or `links-to` edges. If it does not, use its current
documented memory surfaces. Do not assume a proposed host architecture has already landed.
