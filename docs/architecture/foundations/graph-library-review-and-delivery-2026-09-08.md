**BC1 — atom reliability → composition reliability:** conditional on compatible identity/laws, exclusive invariant ownership, coherent reads/publication and outcome handling. Formal fault cases support the need; execution evidence is still missing. Valid only for the qualified combination.

**BC2 — small boundaries → lower total complexity:** a design hypothesis spanning internal, ensemble and temporal scales. Requires consumer/change observations; splitting can increase duplication and coordination. No measured entropy function or cost saving is claimed.

**BC3 — graph result → domain conclusion:** requires domain interpretation and evidence/authority policy. A topological order does not establish pedagogical suitability; a support cycle does not establish grounded evidence.

**BC4 — local execution → external/federated result:** requires declared consistency, coverage and commit/recovery semantics. A local complexity bound or atomicity result does not cross that boundary automatically.

**CW1 — rich model → binary view:** partial and operation-specific; structural reconstruction alone does not warrant algorithm-result lifting. **CW2 — RDF content → assertion/evidence model:** content and assertion mappings differ; equality and provenance are not interchangeable. **CW3 — source → temporal/access/aggregate view:** asymmetric, with explicit selection, time and disclosure. **CW4 — atom decomposition → package decomposition:** many-to-many; package overhead and runtime dependencies do not define mathematical responsibility.
