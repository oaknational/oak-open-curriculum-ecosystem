Design excellence is multi-medium

Every medium consumes the same roles — the token architecture is the portability layer. Nothing is re-specified per format.

Web & mobile

Classes + layout primitives; targets ≥44px; reflow to 320px / 400% zoom; breakpoints sm 640 · md 960 · lg 1280; fluid container padding.

Print & PDF

print.css ships in the cascade: one color-scheme flip makes dark pages print light; meaning-bearing fills keep ink; no unit splits across pages. templates/worksheet is the A4 reference; 12pt body floor.

Editable exports — shipped

Oak Worksheet.docx (Word/Docs/LibreOffice — native heading styles), worksheet.md, Oak Lesson Deck.pptx (PowerPoint/Slides/Keynote — native text & shapes), Oak Lesson Deck (standalone).html (offline, email/USB/VLE, presents in any browser). All user-editable; the .dc.html templates are the source of truth.

Shipped editable files

Oak Worksheet.docx (Word / Google Docs / LibreOffice), worksheet.md (anywhere), Oak Lesson Deck.pptx (PowerPoint / Google Slides import / Keynote), Oak Lesson Deck (standalone).html (offline, any browser) — in each template's folder.

Presentations & projection

Display type scale --font-size-11…14 (64–96px); templates/lesson-deck at 1920×1080 with a ≥24px floor; borders + fills carry hierarchy so slides survive washed-out classroom projectors and sunlight.

DOCX & word processors

CSS can't reach Word — the type ramp maps to named paragraph styles instead (see README): Title ← heading-3, Heading 1 ← heading-4, Body ← body-1 at 13.5pt, Lexend embedded. Reference file ships (left).

SVG

Inline SVG themes like HTML: currentColor icons + .oak-svg-* token classes for diagrams. Asset icons stay monochrome for the filter/mask contracts. See the SVG styling card.

Every one of them

WCAG 2.2 AA is medium-independent: contrast, focus, targets, reflow, plain language hold on paper, screen and projector alike.
