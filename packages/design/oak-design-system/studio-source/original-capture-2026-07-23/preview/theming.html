Build with semantic tokens (--text-primary, --bg-primary, --surface-mint…) and theming is free. oak-theme.js persists the choice; data-theme="system" follows the OS. Windows High Contrast Mode is handled separately via forced-colors. Colour-safe remaps success/error to blue/vermilion (Okabe-Ito) for the ~8% of men with red-green colour-vision deficiency — and state is never colour alone.
