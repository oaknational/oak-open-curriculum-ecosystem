Access is the point

All learners have a fundamental right to access education. WCAG 2.2 AA is the floor in every theme and every re-brand; AAA is the aspiration. Contrast is one clause — the commitment is perceivable, operable, understandable, robust.

The system guarantees

  • Contrast AA–AAA in all four themes, machine-checked by the contrast audit card.
  • Focus — double ring on every interactive class, forced-colors safe. Not removable.
  • Targets ≥44px (md 48px); sm is dense-desktop only.
  • State ≠ colour alone — fills always pair with border + icon + text.
  • Quiet motion (120/200ms) that collapses under reduced-motion.
  • OS preferences honoured — prefers-contrast, forced-colors, colour-scheme.
  • Legible type — Lexend, weight rules on fills, ≥1.5 body line-height, --measure-prose.
  • Colour-safe theme for red–green colour-vision deficiency.

Every build must still

  • Semantic HTML first — real buttons, links, labels; headings in order; ARIA only for genuine gaps.
  • Keyboard — everything reachable, logical order, no traps, visible skip link.
  • Forms — labels, hints and errors wired with aria-describedby; errors say how to fix.
  • Images teach or vanish — meaningful alt text, or alt="" for decoration.
  • Announce changes — role="status"/"alert" for dynamic content.
  • Reflow — usable at 400% zoom / 320px width.
  • Recomposition sanity — composition maps move regions visually; DOM order stays canonical, so tab through and check the focus path still makes sense.
  • Plain language — sentence case, age-appropriate reading level, consistent patterns.
  • Time and speed — no time limits on learning; fast on low-end devices.

Support policy (falsifiable): current stable Chrome, Firefox, Edge, Safari + the last 4 Safari majors; CSS degrades gracefully where light-dark()/color-mix() are missing and oak-theme.js failing to load must leave a working light-theme page (JS is enhancement, never structure). Tested pairs: NVDA+Chrome, VoiceOver+Safari, TalkBack+Chrome; 400% zoom / 320px reflow; Windows forced colors.

The white-label contract (brand.css) carries all of this with it — a re-brand that fails any of it is not finished.
