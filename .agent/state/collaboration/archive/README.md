# Collaboration-state archive

Processed (knowledge-extracted) instance-tier coordination state, archive-moved
out of the live `conversations/`, `sidebars/`, and `handoffs/` surfaces once their
substance was conserved into canonical homes (thread records, ADRs, PDRs, reports,
plans, memory).

- **Untracked by design.** Contents here are gitignored (`archive/*`); only this
  README is tracked. Files are preserved on disk and recoverable, not carried in
  git — the same instance-tier philosophy as `comms-archive/` (ADR-199 / PDR-094).
- **Process, never delete.** A file reaches this archive only after its
  load-bearing substance is verified-conserved in a named live home. Nothing is
  deleted; processing absorbs the substance, and the residual record rests here.
- **Provenance.** First archive-move: 2026-06-21, owner-directed end-of-session
  curator pass (the multi-window strategy/survey rotating-cast wind-down). A
  conservation-verification pass confirmed every moved file's substance lives in a
  named canonical home before the move.
