# v0–Claude Practice composition

## Outcome

We know, from direct evidence rather than platform analogy, which forms of v0 + Claude Code collaboration preserve the Practice's canonical authority, behavioural guarantees, coordination semantics and assurance properties, and which forms should remain invocation-only or unsupported.

## The bet

v0 is useful not only as another possible agent platform but as a deliberately different substrate against which to test the Practice's portability. Its sandbox, browser-visible workflow, automatic Git lifecycle, project skills, external message ingress and in-sandbox Claude Code support expose different mechanisms from the mature Claude/Codex phenotype.

The bet is that exploring that difference can do two things at once: identify a high-value composition between v0 and Claude Code, and sharpen the Practice's distinction between portable capabilities and host mechanisms. This node does not assume that v0 can or should become a first-class Practice citizen; that outcome is already governed by `agent-platform-citizenship`. It exists to generate the evidence needed to decide the v0 instance honestly and to capture any generalisable Practice learning exposed by the comparison.

The research starting point is `.agent/research/agentic-engineering/v0-claude-code-practice-report-2026-08-29.md`.

## Success looks like

- The useful collaboration modes between v0 and Claude Code are distinguished by evidence rather than by vendor feature lists.
- The v0 instance can be classified honestly against the existing `agent-platform-citizenship` outcome: invocation-only, restricted participation, first-class citizenship, or blocked.
- Any proposed v0 mechanism names the Practice capability and firing moment it preserves, rather than treating a Claude-specific mechanism as doctrine or weakening the capability to fit v0.
- Direct trials resolve the highest-value unknowns around bootstrap, skills, coordination/wake, assurance, Git semantics and same-environment collaboration before broad implementation is authorised.
- General lessons about genotype/phenotype boundaries are promoted only when they remain valid beyond v0 and are supported by evidence from the comparison.

This sketch claims no implementation is approved and no v0 capability is proven by the research report alone.
