# Bind and reconstruct the first RDF value and dataset capability

## Goal

The selected complete RDF values/Dataset responsibility in `graph-core` has its
own supported contract, CF grade/evidence and maintained public seam. Higher
GraphView, JSON-LD processing and domain projection retain explicit successor
contracts and consumers; geometry-to-heap is not their implementation home.

## User groups and value

Graph and domain authors can rely on exact RDF identity/equality and set semantics
without inheriting an opaque umbrella or accidental vendor types. Consumer apps
use the eventual published projection, not graph implementation copies.

## Mechanism

Use the [CF dispositions](../../../docs/architecture/foundations/oce-cf-reconstruction.md)
and graph programme [W01–W09 record](../../../docs/architecture/foundations/graph-library-review-and-delivery-2026-09-08.md):
W02 owns RDF/addressability/evidence composition, W07 domain/transport integration
and W09 OCE alignment. Refresh relevant later specialist graph design before
relying on it. Bind RDF term kinds, identity/equality, dataset set semantics,
ownership, mutation/iteration and declared order. Preserve independent domain
assertion/occurrence identities where a projection requires them; a dataset set
does not prove preservation of repeated application occurrences.

Enumerate affected consumers and vendor/emitted type exposure. Construct the
smallest complete selected value/Dataset capability and migrate that closure.
GraphView and RDF-processing successor contracts explicitly bind Result/grade,
supported RDF/JSON-LD round-trip scope, remote-loading policy, canonicalisation
and hash assumptions before their own finite reconstruction slices.

## Acceptance criteria

- **AC1 — repo-safe:** independently expected term/equality/set/ownership fixtures
  and complete CF assurance support the selected responsibility; vendor/emitted
  closure and consumed forms match its exact public contract.
- **AC2 — repo-safe:** actual affected consumers use the new public seam without
  an obsolete fallback; required occurrence/assertion distinctions survive their
  separately specified domain projection or explicitly reject unsupported use.
- **AC3 — repo-safe:** remaining GraphView/processing responsibilities have complete
  source-to-owner/consumer/contract/retirement allocations, with finite required
  decisions and genuine dependency effects; no whole graph gate is imposed.

## Todos

1. Bind the complete first responsibility and independent fixtures from existing
   public consumers; identify lower-grade and emitted exposure dependencies.
2. Construct/qualify that scope and migrate its affected consumers with exact
   source/native/packed evidence.
3. Retire only replaced forms and return the explicit higher graph contracts to
   W02/W07/W09 owners for their bounded next construction.

Default two-review-round bounded stories apply. No team study or universal graph
framework is commissioned.

## Out of scope

No full graph catalogue, completed specialist demonstration claim, automatic
JSON-LD/RDF fidelity, broad code movement or app publication. All useful material
and mechanisms remain OCE; qualification remains distinct from custody.
