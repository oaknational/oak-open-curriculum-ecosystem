- Tracked generated output consumed across workspace boundaries lives in a generated-only workspace (the packages/generated/* tier): every file DO-NOT-EDIT, regenerated wholesale, no hand-written code beyond export barrels; 'the generator lives next door' is not a carve-out — the generator workspace writes into the artefact workspace via a declared dependency edge (oak-api-artifacts, oak-search-contract-artifacts, oak-bulk-artifacts, oak-curriculum-corpus-data).
- Tracked generated output whose regeneration is the same freshness event as its in-workspace generator and whose consumers arrive through that workspace's own dependency edge lives in a dedicated generated/ directory inside the workspace, never file-adjacent to handwritten modules (oak-bulk-data's ground-truth artefacts, oak-curriculum-hub-content's committed JSON).
- Artefacts on different regeneration clocks never share a workspace: upstream-spec refresh, index-design change, ADR-222 bulk-schema truing, and bulk-data mining each get their own generated home — the two-clocks test is what distinguishes a mandatory workspace split from directory hygiene.
- No workspace ever writes committed generated output into another workspace's src/: agent-tools' under-the-hood constant relocates beside its generator as an exported module the server imports, the hardcoded cross-workspace GENERATED_MODULE_PATH is removed, and the existing drift gate is retained.
- Every tracked generated surface has exactly one declared generator with a drift gate; generated regions inside handwritten documents (the AGENTS.md team-alert bootstrap) are bounded and marker-delimited.
- Hand-written views, loaders, and generators over generated data are declared dependants of the generated workspace, never co-resident with the data (oak-curriculum-graph-views vs oak-curriculum-corpus-data; oak-search-index-contracts vs oak-search-contract-artifacts).
- Byte-preserved third-party/studio capture is its own generated class: fenced in a dedicated workspace carrying its own quality-gate boundary (oak-design-studio-capture), converting vigilance fences (README, Sonar exclusion, gitignore re-includes) into structure.
- Where a deliberate, instrument-enforced tracked byte-copy or hand-sync exists, the instrument is the sanctioned mechanism and workspace separation is not forced: the demos' parity-gated public/oak-theme.js copies stay (the validator moves to the workspace owning the single-source contract), and oak-design-system's dtcg hand-sync keeps its same-commit coupling until the studio round-trip regenerator exists.
- Gitignored build output (dist/, .next/, workflow bundles) inside its own workspace remains sanctioned; committed machine-produced INPUT snapshots (schema caches, canonical-url maps) live with the acquisition workspace, not with pipeline code; generated docs get a declared generated-doc path when they cannot move (served-tool-table.md).
- Handwritten editorial content (ground-truth corpora, synonym vocabularies, EEF data-as-code snapshots) is not generated output and is never governed by the generated rule — it separates on editorial-lifecycle and licence grounds instead (OGL content vs MIT code).
