## 2. The six facet designs (summaries; full decisions absorbed into the plan)

- **F1 — mechanical substrate.** A checked-in, owner-ratified surface-class freeze rule
  (never a per-file filter); one atomic S0 commit landing verbatim frozen copies + a
  sha256 line-level denominator + identity proofs; a standing re-hash gate in
  `repo-validators:check`; denominator re-derivation after every merge with a versioned
  append-only amendment mechanism; three overlapping deterministic regex nets emitting a
  verbatim, digest-carrying `inventory.jsonl`; residue clustering with declared orphan
  bounds and a scripted planted-synthetic-orphan proof; granularity-agnostic exact-cover
  tiling, mutation-tested; ~10 scripts homing in `agent-tools/src/refounding/`; global
  stable points S0/S1/S2 then per-area batches; zero LLM tokens at run time.
- **F2 — worker layer.** Thin by design: exactly two roles. `refound-reader` (the second
  blind net: Read-only, bounded turns, verbatim quotes + anchors only) and
  `refound-locator` (single-target, zero-tools, dispatcher-inlined windows). Over-inclusion
  doctrine (workers only ADD candidates — never subtract, filter, rank, classify);
  schemas with no free-text; 100% four-step verification with full-set byte equality and
  hidden known-answer floors in every dispatch; refusal (JUDGEMENT-REQUIRED) terminates
  the task and blocklists its spec hash — redesign mints a new hash, so re-wording a
  refused task at a worker is structurally impossible; a typed dispatch ledger makes
  batch completion arithmetic.
- **F3 — judgement and error correction.** Judgement placed, never eliminated: a
  placed-judgement map with everything below the line forbidden to carry judgement; a
  closed conserving disposition taxonomy with NO discard class (conserve-by-default as a
  type-system absence); two-lens quorums honouring the measured n_eff ≈ 1.4 (lens count
  is the wrong lever); mechanical probes decide re-expression-ending classes first, then
  cross-regime concurrence, else conserve-to-holding flagged terminal-candidate;
  disposition-class-stratified challenge (as designed: ALL loss-bearing rows challenged,
  probe classes mechanically re-verified — one point superseded by the donor-seat
  correction, §3 row 22: coverage is universal, stratification narrows the question);
  ~15 sealed known-answer canaries + three planted defects behind a deterministic
  breaker; an eight-item scripted batch-close loss check; a five-level error-correction
  ladder ending in pre-declared halts.
- **F4 — intent layer and lanes.** The intent layer is the standing owner-ratified
  wording quoted verbatim (the mission; "deliver Oak's rigour at reach and at pace"; the
  three streams; the signed-off APP/TOOLS/FRAME choice registry) — never re-authored.
  Lanes are registered axis values in a machine-validated lane registry forming a
  partition, each anchored to a strategic choice, a named capability, or the single
  conserving holding lane; five validator rules, each prove-it-fires. Holding-lane
  content is conserved as `kind: strategic` plans with promotion triggers (never an open
  paused state); >20% of the corpus held falsifies the taxonomy. Newly-identified lanes
  exit only via an additive choice/capability proposal or holding. Coexistence is
  governed by sanctioned write classes + an accretion log; two scripted additive banner
  classes; live-lane coordination uses the existing claims/comms/commit-queue substrate
  with defer-don't-contest.
- **F5 — recomputable state.** Kit item 9 affirmed with a correction: build the
  plan-state recomputation tool FIRST as one deterministic engine behind two adapters — a
  permanent gate adapter over V0.1 proof-typed frontmatter, and a disposable audit
  adapter feeding the same engine from the frozen inventory via a versioned
  status-mapping table — so the two-verdict audit is a zero-token recomputation and the
  refounded corpus is born gated. Proof-typed todos land as an additive V0.1 extension
  (owner re-ratification: V0 todos are LOCKED). Six-kind proof taxonomy mapped to this
  estate's recomputers (gate registry, probe templates with closed survivor sets, git/gh
  facts, ratified records); unmappable statuses are a named UNMAPPED residue class;
  >20% UNMAPPED halts for a table v2; attested-count is a reported signal, never a gate;
  the exact team-state join defers to the composed-liveness lane via an additive claims
  schema pointer.
- **F6 — sequencing and roadmap.** Three eras (current estate → refounded corpus →
  intent graph); the refounded-corpus milestone is a committed stable point with
  standalone acceptance, valuable even if the graph era were never to run. The
  refounding inserts under ADR-200 with WS6's harvest substrate becoming the refounded
  corpus and the no-loss audit composing transitively (old→refounded ∘ refounded→graph);
  WS2/WS4 never wait (write-surface disjointness, additive authoring, schema pinning,
  Director-scheduled gates). Borrow corpus-generalisation doctrine, priors, and tested
  deterministic modules; never wait for its landing set — and this arc produces its P2
  substrate. Pilot = the whole `discovery` area (16 md / 9 plans / 3,537 lines; no
  active lanes; exercises the holding lane; fallback `user-experience`); one whole-estate
  freeze; batches ascend by liveness with `product-development-governance` last; no
  long-lived working branch — per-batch worktrees landing stable points to `main` via PR.
