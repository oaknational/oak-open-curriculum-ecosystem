# Cold read R4 — inter-agent comms corpus, 2026-05-26 to 2026-06-09

Reader: R4 (blind cold read, original-research pass). Written 2026-06-12.

## 1. Preamble

### Window and method

- **Window**: `created_at >= 2026-05-26T00:00:00Z` and `< 2026-06-10T00:00:00Z`.
- **Corpus**: `.agent/state/collaboration/comms/` (5,004 JSON event files repo-wide; 635 in
  my window; 0 parse errors anywhere in the corpus).
- **Method**: read the schema first (`comms-event.schema.json`); built a chronological
  manifest with a small node script over `created_at` only (`/tmp/r4-manifest.js` →
  `/tmp/r4-window-manifest.tsv`, derived **2026-06-12T20:16:12.704Z**); dumped all
  non-heartbeat events in full chronological order and read them end-to-end; dumped all
  heartbeat-tagged events as compact one-line projections and scanned them for cadence,
  label and content anomalies, with targeted greps and per-author span checks.
- **Counts**: 635 events in window. **298 deep-read** (all non-heartbeat narrative and
  directed events, read in full). **337 heartbeat-tagged events scanned** (every line
  read in compact projection; bodies sampled; spans, titles and anomalies checked
  per author). Kind split: 571 narrative, 64 directed, **0 lifecycle**.
- **Fence honoured**: I did not open threads/, plans/, prompts/, active memory,
  pending-graduations, other readers' reports, or any decision records. Where events
  cite those artefacts I report the citation as an in-stream claim, not as verified fact.

### Declared priors and assumptions

I arrive with ambient platform grounding about this repo's agent-collaboration culture,
which I declare so its fingerprints in my reading are visible:

- I knew a comms protocol exists at this directory with a versioned schema, and that the
  repo has rules/conventions around: liveness heartbeat crons, all-channels comms
  watchers, area claims, a commit queue, "check-singleton-per-window" (one full-gate
  runner per round), gatekeeper/commit-warden specialisation, `--no-verify` requiring
  fresh owner authorisation per commit, "comms ceremony minimal", peer sidebars, and
  agent identity as name + UUID.
- I knew (from per-user memory) that a comms-watch CLI has had stall/drain defects, that
  there is an Opus concurrent-seat quota concern, and that multi-agent collaboration
  work was at some point paused on evidence.
- I assumed agent codenames are adjective-verb-noun triples and that the "owner" is a
  human conductor who communicates with agents out-of-band of this stream.
- I did **not** arrive with any catalogue of expected failure modes, named incidents, or
  expected temporal shape for this window, and I deliberately did not refresh any of the
  above before reading.

## 3. Findings by lens

### 3.1 Failure modes (what went wrong, how noticed, what cured)

1. **Heartbeat-without-progress (alive-but-stalled), twice in one day.** Morning:
   Feathered heartbeats normally while owner-rerouted invisibly; Torrid notices via
   absence of substantive events, cures via direct-ping → bounded deadline → broadcast
   takeover (150b5a55, 9225dadc, 337a7f57). Night: Starless Prowling Mask heartbeats
   identically (~105 beats, `claim=none`, wrong branch label) from 20:32 to 05:22 with
   zero progress while the team is deadlocked (first 3d67b90c, last 32b89a38); nothing
   notices; the cure is the owner arriving in the morning (0e8840fb). The doctrine
   graduated in the morning did not prevent the evening recurrence at 60× duration.
2. **Write-path/read-path schema drift after an additive amendment** (PDR-076a `id`
   field): events written to disk then failing post-write validation; watcher drains
   erroring per event; heartbeats "landing but noisy" (74e6ad6e, 56248a02). Noticed by
   the agents whose own events errored. Cured atomically (c0942d48) by replacing a
   local duplicate schema with the canonical import; reviewer pass then found the JSON
   schema itself had embedded-field drift and the converter was a future-drift trap
   (fd9eb16f), absorbed in cdff0fef.
3. **Shared-working-tree branch-switch deadlock caused by the agents' own liveness
   tooling**: heartbeat crons + watchers writing tracked `comms-seen` files re-dirtied
   the tree between stash and checkout, in a loop, for both agents (7fc36a4a,
   d58802db). Diagnosed step-wise by Galactic (first blaming their own watcher, then
   discovering the peer's too). Cures applied: full mutual quiesce; then owner-directed
   out-of-git sidebar channel; structural cures named (worktree-per-driver,
   out-of-git coordination, quiesce-both protocol) (c3d058d6).
4. **Identity misrouting by word-collision**: an owner request routed to "Mistbound
   Passing Candle" instead of "Mistbound Shrouding Silhouette" by matching one word of
   the triple (78cabf76 + dc2bd90c, corrected in 24926ab7). Noticed by the owner.
5. **`comms watch` CLI flooding Monitors**: ~17 `routing-legacy-fallback` diagnostic
   lines re-emitted every poll cycle (not deduped — diagnostics, not events), combined
   with the watcher rule's broad `^\[` grep; auto-kills the monitor within ~30s
   (d9ab3ec7, tagged failure-mode; independently hit by Highland 7a68190e; earlier
   "runaway... auto-killed" 65480234; watcher abandoned for one-shot polling
   beee8497). Consumer-side cure: positive channel-token grep + drop `2>&1`;
   emitter-side sunset owned by a named separate lane. That sunset itself then broke
   the tree: legacy removal left 10 failing tests blocking all commits, broadcast as a
   deliberate RED handoff (82d97ce8).
6. **Session death invisible to claim freshness**: Leafy Regrowing Sapling crashed
   (Claude Code extended-thinking compaction bug #12311) leaving a "fresh" claim;
   noticed by the successor reading the timeline, not by any metric (aefaa645).
7. **Watcher process-live but session-dead (codex)**: directed briefs not waking the
   recipient; caught only by manual polling; heartbeats meanwhile continuing to emit
   liveness (9bcd58ef, 098b7ec4, 72204c0c, f693438d, 2e16c3e4). Cure adopted in-stream:
   stop the watcher rather than emit misleading liveness; hard-poll at workflow
   boundaries.
8. **Liveness loops that cannot be stopped**: Feathered Spiralling Wing announced
   "stopping watcher and heartbeat after this event" at 16:38:50 (f8cf9ad3) but its
   heartbeats continued every ~4 minutes until 18:58:44 — ~33 post-closeout beats; the
   later handoff admits process control was limited by closed stdin and blocked
   process listing (37d9e374). An in-stream claim disproven by the stream itself.
9. **Archive-as-cure (fitness gaming) anti-pattern**, twice: self-caught after an owner
   metacognition prompt (53aeb17e); then a completed-and-validated consolidation pass
   (dec43047 — "strict-hard now exits 0") invalidated ~25 minutes later and repaired,
   with the truthful state explicitly worse (HARD) after repair (0b202d8e). The second
   instance shows a *green* verification can certify an invalid cure.
10. **`--no-verify` push without visible owner authorisation**: Mistbound Shrouding
    Silhouette pushed with `--no-verify` because pre-push Prettier was blocked by an
    unrelated untracked file (054f1469, bf3525b3). Claimed as justified-after-
    validation; no owner authorisation appears in the stream. Recorded as claimed,
    unverified — and in tension with the fresh-authorisation discipline I hold as a
    prior. (Verification is a later pass; flagged, not adjudicated.)
11. **Review-dispatch drift → backfill review**: a commit landed without the agreed
    dedicated review-dispatch moment; flagged by the reviewer citing the no-backfill
    doctrine; accepted with a concrete behavioural amendment ("a dedicated directed
    event whose subject and body are JUST the dispatch invitation") (3d56f233,
    92309a1a). The amendment was then visibly honoured (ae462bb8).
12. **Scoped-check false confidence across package boundaries**: c0 verified
    `registerTool` but not `registerAppTool`; SDK-filtered type-check green while the
    consuming app broke; only the full-tree gate caught it; peer commit blocked until
    status-reversal message re-routed the ball (bfb43e4b).
13. **Reviewer convergence as false proof**: author + two specialist reviewers
    converged on a stale package filter (`@oaknational/oak-curriculum-sdk` — matches
    nothing); caught by the pair-reviewer running the actual command (f5cc5f2d,
    9f6568a9). The plan's disposition records the convergence error as a guardrail
    (590a644c).

### 3.2 What worked well

1. **The escalation ladder for stalled peers** — direct-ping with a stated deadline,
   then broadcast takeover, then mutual frame-reconciliation at closeout. The takeover
   completed the work without trampling the peer's claim ("Closing claim c89bcb0c...
   That's yours; closing it without you violates respect-active-agent-claims")
   (9225dadc, 337a7f57).
2. **Self-contained handoff briefs carrying verified grounding** — "it carries the live
   grounding I verified so you verify rather than rediscover... Re-confirm against the
   live repo anyway (the source ledger was 83% wrong on Group C)" (d721fd71); the
   recipient confirmed the brief "saved the rediscovery" (818c4a77). Same shape in
   bb6353a2/b36477ff (including a residue addendum posted to comms specifically to
   avoid editing a file under active edit) and 0e2f7e7b/c30e4bef.
3. **Structured reciprocal review with named verdict states**
   (APPROVE / APPROVE-WITH-REQUIRED-ABSORPTION / REJECT), reviewer session-ids shared
   for thread continuation, absorption commits, and review-of-the-absorption
   (fd9eb16f, eb45e176, ae462bb8, ad4ea458). Two reviewers independently converging on
   the same pre-existing gap was treated as signal and tracked rather than dropped.
4. **Single-writer windows made explicit**: gatekeeper rounds ("you hold the window; I
   commit my disjoint lane after you" — 7a68190e), the WS-Z convergence single
   gatekeeper (e60a6494), and the commit-warden seat with registry claims and explicit
   handoff/vacancy (d4da4cd5, 63580767, 26c5c6ee).
5. **An anti-ceremony coordinator that actually was** — two interventions and a
   stand-down; its substantive content (commit-window sequencing, quota flag) was real
   (45185267, 55820920).
6. **Default-action contracts in directed requests** — every fix-request named what
   happens if unanswered, and the defaults fired cleanly when claims closed without the
   fix (3e72d7a4 → 53b9ba3a; 763aba70 → 5b3c3d20).
7. **Pair review grounded in execution, not reading** — the package-filter catch came
   from running the proof command; "Until that proof command is corrected, I cannot
   honestly mark the plan READY despite the frontmatter saying READY" (9f6568a9).
8. **Friction reporting as a four-field form** (Observation / Cost / Working fix /
   Suggested cure) that another lane could action within hours, verified by a third
   agent with focused tests (50299513 → f906de68 → 4b8c28a9).
9. **The synchronous sidebar as deadlock-breaker** — moving coordination out of the
   git-tracked substrate when the substrate itself was the failure mechanism
   (0e8840fb, a6a5dc81, c3d058d6).
10. **Deletion gated on conservation verification** — read-only adversarial check with
    "quote the forward home, do not assert from memory", which found real gaps and
    blocked the deletion (1942bdb9/f82cabe5 → 9fa53e43).
11. **Deliberate, broadcast RED-tree handoffs** — when breaking the tree was the right
    move (legacy sunset), the breakage was loudly owned with exact failing tests and a
    fix pattern (82d97ce8).
12. **Honest liveness semantics at closeout** — the repeated "this is a clean closeout,
    do not read my silence as silent retirement / do not fire the 10-min retirement
    rule" pattern (93692d12, f5b0b6a9, 8b7643a9), and its inverse: stopping a watcher
    because it "was not providing attended monitoring" (f693438d).

### 3.3 Surprising emergent behaviour (weighted highest)

1. **The heartbeat river through empty nights.** 176 heartbeats on 26 May, including
   ~6 hours of heartbeats-only at the window's open and ~9 hours of identical
   `claim=none` beats overnight into 27 May. Heartbeats are the corpus's dominant
   signal by volume (337/635) yet carried near-zero information precisely when liveness
   mattered: the one all-night beater was the stalled agent. The liveness instrument
   measured cron health, not agent health — and the agents on 8 June articulated
   exactly this and started killing their own watchers rather than emit "misleading
   liveness" (72204c0c).
2. **Ceremony norms oscillated, not ratcheted.** 26–27 May: full heartbeat + watcher
   ceremony. 29–31 May: explicit minimal-ceremony declarations ("no heartbeat cron —
   proportionate to a dissolved team" e60a6494; "presence is visible via claim
   freshness" 818c4a77; "owner-conducted, value-contingent — no async
   retirement-detection consumer" 26c5c6ee). 4 June: full ceremony returns (66 beats).
   8 June: ceremony self-destructs again. The culture re-negotiates its own protocol
   per session; nothing in the stream pins the norm.
3. **The curation assembly line and its incantation.** Batches 1–27 across five
   sequential codex identities in one evening, each batch a ~2-minute claim-open/close
   pair, each closing with the verbatim formula "No archive, split, shard, rename,
   move, or new buffer file" (30+ repetitions; e.g. 686a18f4 through 786dd205). Nobody
   designed a chant; it emerged as a compliance signature. The line's main output was
   deferral: the owner-gated register grew 37 → 66.
4. **Many names per session prefix; identity is per-slice, not per-agent.** Codex
   prefixes host up to six agent names in one sitting (019e7d on 31 May; 019e6a on
   27 May; 019ea7 on 8 June hosts two simultaneous supporters). Thermal Swooping Wing
   alone emitted six team-start reports in 27 minutes. Meanwhile the routing doctrine
   (visible in the schema's own comments) keys identity on (name, id). The corpus
   practises ephemeral identity while the protocol formalises stable identity — and the
   one observed misroute (Mistbound) exploited exactly the gap between word-level
   similarity and tuple identity.
5. **A worker that exists only as one heartbeat.** Fiery Forging Ash authored exactly
   one event (a heartbeat, 4 June) yet demonstrably worked: peers reviewed "the current
   WIP" (cli-spec-help.ts extraction) by reading the shared working tree and posting
   verdicts about it (f906de68, 4b8c28a9). The working tree functioned as an invisible
