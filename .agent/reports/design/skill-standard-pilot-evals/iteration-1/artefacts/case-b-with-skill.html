Pick a theme, keep it

Choose light, dark, high contrast or colour safe from the menu above and it sticks — this page remembers your choice in the browser's local storage and re-applies it on every visit, before anything paints. Leave it on Match device (the default until you choose something else) and it follows your operating system's own light or dark setting instead.

This card themes itself

Every colour on this page — text, borders, this card's pastel fill, the signature offset shadow — comes from the design system's semantic tokens, so switching the theme above repaints this card without touching a single line of CSS here.

How this works

  • Five themes are always on offer — Light, Dark, Match device, High contrast and Colour safe — never a subset.
  • Picking one calls oakTheme.set(name), which writes localStorage["oak-theme"] and sets data-theme on <html> — every token on the page repaints from that one attribute.
  • On the next visit, the same script re-applies the stored choice before the page paints, so there's no flash of the wrong theme.
  • Until a choice is made, this page defaults to Match device, which resolves to light or dark from the operating system's own setting — and keeps following it live if the OS setting changes.
