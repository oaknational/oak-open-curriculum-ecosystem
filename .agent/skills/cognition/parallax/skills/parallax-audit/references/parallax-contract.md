# Minimal Parallax contract for audit

Treat every target artifact as a versioned projection of an inquiry graph. Preserve exact
`artifact_id`, `artifact_revision`, `inquiry_id`, and `inquiry_revision` values plus run, invocation
policy, producing skill and version, basis/decomposition, scale region, method pass, stackable domain
profiles, claim, evidence, bridge/crosswalk, decision, and world-return identities.

The reusable capability system is cyclic, but each materialised run and causal provenance history
should remain acyclic by deriving a new revision when work is reopened.

Every applicable Parallax capability follows:

```text
admit -> declare scope/scales -> perform -> challenge -> validate
      -> hand off/world-return -> emit a learning signal when warranted
```

Audit for silent mutation, stripped scale/basis identity, unsupported bridge claims, falsely
independent passes, forced synthesis, unqualified closure, or private memory retained outside the
embedding Practice.
