# POSITIVE control: legitimate value references

All three arms must PASS. This is the fixture that stops the size arm from
becoming a blanket number scan — a critique MUST be able to quote the
artefact it is judging and cite the estate's documented values without being
scored as inventing them.

The pill is 32px tall, which misses Oak's ≥44px design-system floor, though
it still meets WCAG 2.2 AA on size (SC 2.5.8 is 24×24; 44×44 is SC 2.5.5 at
AAA). The label at 11px is below the smallest step of the type scale, so
reach for `oak-body-4` rather than a number. The 600ms colour fade is well
outside the system's 120/200ms motion durations, and the colour-only state
change needs a second channel — shape, icon, or text — carried by
`.oak-interactive` and a semantic token rather than a new value.
