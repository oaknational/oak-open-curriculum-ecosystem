# Innovation Kit capability architecture — dated synthesis migration note

- **Date:** 2026-08-30
- **Status:** decomposed research synthesis; retained as a stable link and provenance pointer
- **Original evidence pin:** PR 25 head [`4915fe1826372d9b0b6ee18322500c811128f41c`](https://github.com/EngraphCode/oak-open-curriculum-ecosystem/commit/4915fe1826372d9b0b6ee18322500c811128f41c)

The original version of this file was the first whole-system synthesis of the Innovation Kit. It
correctly widened the subject beyond demos and innovative packages to include purpose, authority,
experience, conventional product foundations, operation, evidence, evolution and retirement.

It also combined too many responsibilities: foundational thesis, conceptual vocabulary,
capability taxonomy, ownership, contracts, profiles, pipelines, current-estate evidence, examples,
proof planning, risks and provenance. Calling that paper the “single working architecture” made a
large research report the permanent interface and conflicted with the repository principle that
documentation is infrastructure with one canonical home per concern.

The content has therefore been decomposed into the
[proposed definition corpus](definition/README.md). Git history preserves the original working
paper; this stable path now explains where each responsibility lives.

## The durable finding

The deconstruction did not merely reveal a longer list of tools. It revealed that a product makes
promises across people, educational meaning, authority, interaction, state, rights, representation,
operation, evidence and time.

The resulting definition is:

> The Oak Innovation Kit is the portable, governed part of a complete product-creation system. It
> compresses recurring decisions and mechanisms so people and agents can create truthful,
> excellent, operable experiences quickly, without hiding differences in meaning, authority,
> rights, state, failure, evidence or stewardship.

Managed PostgreSQL, SQL, migrations, ORM-adjacent data access, vector operations, object storage,
jobs, identity, observability and other conventional foundations remain important. Their gaps in
the current estate diagnose incomplete product closure; they do not organise the definition.

## Authority boundary

The [Innovation Kit strategy](../../../docs/strategy/stream-innovation-kit.md) remains the durable
strategic authority. The proposed definition is research until reviewed and ratified through the
appropriate architecture or Practice surfaces. Dated evidence does not define the target, and
worked examples do not create rules.

No implementation proof or provider is selected by this migration. Later planning should consume
the definition only after its conceptual, authority and reader boundaries are accepted or amended.
