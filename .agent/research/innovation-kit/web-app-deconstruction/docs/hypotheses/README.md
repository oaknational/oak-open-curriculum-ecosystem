# Architecture hypothesis register

These hypotheses are starting positions for investigation. None is an architecture decision. H001-H005 derive candidate contracts from OWA and Oak Components evidence. The premise-first method and uncompromising excellence are adopted research policy in the charter; H006-H007 test the architectural effects of premise-derived boundaries and the kit's ability to encode excellence intrinsically, not whether those governing decisions matter. H008-H012 graduate the database, public API and OCE premise-collapse propositions into falsifiable experiments; they do not select those candidate concepts or an implementation topology.

## Status model

| Status     | Meaning                                                                        |
| ---------- | ------------------------------------------------------------------------------ |
| Proposed   | Plausible enough to investigate; discriminating evidence is not yet collected. |
| Testing    | An investigation or experiment is actively gathering evidence.                 |
| Supported  | Evidence supports using the claim within a stated scope.                       |
| Weakened   | Some predictions failed or the useful scope is narrower than claimed.          |
| Rejected   | An invalidator was observed or a competing explanation is materially stronger. |
| Superseded | A later hypothesis incorporates what was learned more precisely.               |
