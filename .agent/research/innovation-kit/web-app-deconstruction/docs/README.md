## Artifact types

| Artifact           | Purpose                                                               |
| ------------------ | --------------------------------------------------------------------- |
| Current-state map  | Record what exists and what it currently does.                        |
| Journey trace      | Follow a user outcome through routes, state, services and operations. |
| Concept lens       | Reframe evidence around a distinct value, failure or authority.       |
| Premise record     | Challenge why an element is needed before proposing architecture.     |
| Hypothesis         | Make a proposed improvement falsifiable before adopting it.           |
| Investigation      | Gather evidence that discriminates between competing explanations.    |
| Experiment         | Record a focused test that discriminated between claims.              |
| Decision           | Record a choice only after its evidence and trade-offs are visible.   |
| Teaching approach  | Describe how validated understanding could become a guided path.      |

## Record lifecycle

- Current-state maps and journey traces are immutable evidence snapshots. Amend factual errors, but create a new dated snapshot when source revisions materially change the finding.
- Premise records and hypotheses carry `status`, `evidence_snapshot` and `last_updated` metadata. Their conclusions must change when decisive evidence changes.
- Registers, coverage and synthesis are living views. Their links and status must be updated in the same change as the evidence that alters them.
- Experiments record their original inputs, method, expected observation and
  measurement limits. Negative and inconclusive outcomes remain in the record;
  the retired harness provenance identifies where exact historical code lives.
- Decisions are created only after the relevant premise, alternatives, evidence, invalidators and reopening conditions are explicit.

## Reading rule

Current-state documents describe mechanisms, not recommendations. Hypothesis documents describe possibilities, not commitments. A recommendation becomes a decision only after its invalidators have been tested with proportionate evidence.
