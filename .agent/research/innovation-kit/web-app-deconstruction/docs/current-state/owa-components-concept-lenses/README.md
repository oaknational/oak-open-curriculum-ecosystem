# OWA and Oak Components: concept lens portfolio

## Purpose

This is the control record for a portfolio of differentiated attempts to understand
Oak Web Application (OWA), Oak Components and the boundary between them. The
existing recursive architecture atlas follows authority, projection, execution,
state, interaction and assurance. This portfolio deliberately changes the
question: it asks what becomes visible when the same evidence is treated as an
educational service, a language, a temporal system, a safety boundary, an
evolving organisation, a public good, a consumer framework or a resource-using
operational system.

The work uses OCE's pinned
[`concept-exploration`](https://github.com/oaknational/oak-open-curriculum-ecosystem/blob/bd878a3a550c8e5e5d21163a6d0962cebdaf43fa/.agent/skills/concept-exploration/SKILL-CANONICAL.md)
Practice. Each lens must complete all four movements:

1. reflect on literal observations and inherited assumptions;
2. define a mechanism-neutral problem space;
3. reopen competing explanations and possible solution shapes; and
4. synthesise only warranted proposals, each with a falsifier.

The result is current-state research. It is not an OWA or Components remediation
plan, a target OCE architecture, or an argument that every lens deserves a
framework subsystem.

## Orthogonality rule

Two names are not two lenses merely because they come from different books. A
lens belongs in this portfolio only when it changes at least one of:

- the primary subject being protected or enabled;
- the unit of analysis;
- the failure signal;
- the time horizon;
- the authority entitled to decide; or
- the evidence that could falsify the synthesis.

Partial overlap is expected because one system serves the same people. The
decisive test is whether two lenses could reach different, independently useful
judgements about the same mechanism. Accessibility and performance qualify, for
example, because an interaction can be fast but unusable by keyboard, or fully
operable but too slow for the task. Coupling and pedagogy qualify because a
well-factored implementation can encode an educationally invalid outcome.

The rule applies to the question, not merely the lens name. The adversarial
review identified passes including assurance epistemology, complexity
classification and distributed consistency that recurse more deeply into
seams already present in the architecture atlas. They remain useful because they
add a formal frame, observations and falsifiers, but they are classified as
**recursive deepening**, not new orthogonal dimensions. Other passes can
**triangulate** an existing finding from an independent failure signal. The
portfolio therefore distinguishes:

- **orthogonal expansion**: changes the protected subject, unit or failure;
- **recursive deepening**: examines an existing seam with a more discriminating
  framework or new evidence; and
- **triangulation**: reaches a compatible finding through an independent lens.

No claim is made that every row is independent of every earlier research record.
Two within-portfolio relations are also explicit. Component public-API
compatibility and data-contract compatibility are recursive specialisations of
the broader producer-consumer promise: the former protects source, runtime and
behavioural use of the kit, while the latter is narrowed to correspondence among
serialised, generated and runtime-validated data models. Component governance
and evolutionary architecture similarly triangulate contract change at consumer
and whole-system scales. Shared evidence is not evidence of independence.

## Research journal

### 2026-07-19: adversarial gap closure and synthesis recorded

**Observed:** The initial 49-pass register underrepresented power, incentive and
long-horizon obligations. Full passes added curriculum contestability,
institutional incentives, human-rights duty and remedy, and authentic digital
preservation. The resulting 53 passes all complete the Concept Explorer
structure.

**Changed assumption:** Adjacent coverage is not always sufficient. Public
value can improve while an individual right lacks a remedy; current lifecycle
and redirects can work while no authentic object remains intelligible in future;
provenance can exist without a legitimate challenge path; and code ownership can
exist without incentives for ecosystem stewardship.

**Qualification retained:** The final set is not 53 independent ontologies.
Each pass is classified as orthogonal expansion, recursive deepening or
triangulation. Named architecture patterns and adjacent theories were collapsed
when they supplied a method or solution vocabulary without changing the unit,
authority, failure or falsifier.

**Durable result:** [Cross-lens synthesis](./synthesis.md).

### 2026-07-19: human, semantic and structural passes recorded

**Observed:** Thirty-one passes now separately examine human value; domain
meaning and time; and structure, evolution and operations. Each completed all
four movements and recorded immutable evidence, changed assumptions, warrants,
falsifiers and unresolved evidence.

**Convergence retained:** Consequential product meaning repeatedly crosses the
OWA/Components boundary, while authority, acknowledgement and evidence often
remain elsewhere. Migration, configuration and provider integration are active
architectural states, not external implementation detail.

**Difference retained:** Human-value lenses judge realised benefit and harm;
semantic lenses judge meaning and truth over time; structural lenses judge
change propagation, containment and control. Agreement between them is stronger
evidence precisely because their failure signals differ.

**Gap found:** The first register did not independently test service operations,
legal/content rights, localisation, channel projections, measurement validity or
decision reversibility. Six passes were added rather than assigning those
questions to a vaguely adjacent lens.

### 2026-07-19: component and kit boundary pass recorded

**Observed:** Twelve differentiated boundary passes are now recorded, from design
semiotics through executable documentation. They converge on three analytical
levels - foundations, interaction grammar and outcome recipes - but do not
establish that these levels need separate packages or owners.

**Changed assumption:** “Component API” is not one contract. Meaning,
composition validity, consumer compatibility, responsibility hand-off,
browser capability, adaptation, design policy, runtime delivery, teachability,
governance, placement and examples each have independent failure signals.

**Durable result:** [Component language and kit boundary](./component-language-and-kit-boundary.md).

### 2026-07-19: portfolio opened

**Observed:** The existing recursive OWA atlas already covers five architectural
views. Reusing those names would increase documentation volume without changing
the evidence question.

**Changed assumption:** “More perspectives” does not mean collecting named
frameworks. It means finding independent units of value, harm, meaning, time,
change and proof.

**Decision for this pass:** Keep every qualifying pass separate through Movement
4, then classify each convergence as orthogonal expansion, recursive deepening
or triangulation. The register began at 49 and grew to 53 through adversarial gap
review. Convergence and collapse are synthesis results, not reasons to merge
questions before they have had a chance to disagree.
