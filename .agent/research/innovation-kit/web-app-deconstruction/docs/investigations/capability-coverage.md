# Capability coverage

## Purpose

This ledger prevents the available files from being mistaken for complete understanding. It records which areas have source-backed maps, which have only representative slices, and which still require user, domain, operational or target-system evidence.

`Mapped` means the recorded source scope is traceable, not that its purpose has been validated or an OCE design selected.

## Coverage states

| State            | Meaning                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| Mapped           | The stated source scope has a dedicated evidence record with observations, unknowns and implications.        |
| Partial          | Representative mechanisms are traced, but important variants, evidence sources or outcomes remain uncovered. |
| Not started      | No dedicated investigation yet establishes the capability or its need.                                       |
| External unknown | Repository evidence identifies the question, but deployed systems or stakeholder evidence are required.      |

## Coverage rule

The [outcome and capability atlas](./backlog.md) must consume this ledger. A missing dedicated trace is not evidence that a capability is unimportant, and a mapped source mechanism is not evidence that its outcome remains necessary. Update the state, evidence link and remaining gap whenever an investigation materially changes coverage.
