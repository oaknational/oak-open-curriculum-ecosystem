## Authority and source boundary

Placement records research; it does not ratify its hypotheses, change the
Practice, install capabilities or authorise experiments. Copied skills,
directives and TypeScript inside the ZIP are frozen evidence, not active
instructions or maintained executable code. The experiments remain proposals.

The original research commission kept its materials private. The owner's
subsequent request to open this package as a PR into public Engraph OCE is the
authority for this transfer, including the source exports in the archive.
Statements in the original record such as "no publication was performed" or
"local Library directory" describe the research run before this import;
they are not claims about the repository copy's visibility or location.

The readable Markdown files add one import notice and replace local links to
archived evidence with an explicit archive link and internal filename. The report
uses multiline footnote definitions compatible with the repository's Markdown
validator. Their substantive research text is unchanged. The CSV retains every cell value,
with line endings normalised from CRLF to LF for repository storage. The
original Markdown and all original hashes remain in the ZIP. The import
manifest records these differences so the reading copies cannot be mistaken
for the exact original bytes.
