# Agent teams and fleets — a survey of everything this repo holds on the subject

- Date: 2026-08-22
- Kind: survey / routing map (report, not doctrine)
- Method: five parallel read sweeps over `.agent/research/`, `.agent/reports/`, the governance layer (`.agent/directives/`, `.agent/rules/`, `.agent/practice-core/`), `docs/`, and the operational machinery (`.agent/skills/`, `.claude/agents/`, `agent-tools/`, `.agent/memory/`, live collaboration state). Every claim below is anchored to a repo path; the cited file is the authority, this survey is a map.
- Scope: notes, research, guidance, doctrine, tooling, and run records on agent teams, agent fleets, fleet topologies, multi-agent organisation, communication, division of work, and decision-making.

## 0. Orientation: two corpora, one estate

The repo's multi-agent material splits into two bodies of work that use different vocabulary:

1. **The team/coordination corpus (May–Aug 2026)** — live multi-agent *sessions*: 2–8 concurrent named seats sharing a checkout or worktree set, with roles (Director, Implementer, Marshal, Curator), comms events, claims, heartbeats, handoffs, and succession. "Team" almost always means this.
2. **The fleet/survey corpus (Jun–Aug 2026)** — *dispatched fleets* of 10–1,000 disposable sub-agents run as instruments: review fleets, corpus-analysis pipelines, design panels, landscape surveys, with baselines, falsifiers, reducers, and adversarial verifiers. "Fleet" almost always means this.

Both sit on one substrate: portable doctrine in `.agent/practice-core/decision-records/` (PDRs), repo phenotypes in `docs/architecture/architectural-decisions/` (ADRs), enforcement in `.agent/rules/`, workflow in `.agent/skills/`, tooling in `agent-tools/`, and run evidence in `.agent/reports/` and `.agent/research/`.

## 2. Doctrine — `.agent/directives/`

- `agent-collaboration.md` — the richest single multi-agent document. Core commitments: the protocol gives agents information about each other's work and means to discuss overlap; it never mechanically refuses entry (every rule is a tripwire, not a lock). No orchestrator, no peer veto; the owner is the final tiebreaker. Liveness needs injected asymmetry (two polite peers deadlock). The Coordinator role is opt-in and triggered by super-linear coordination symptoms, not agent count; worked evidence shows a 4+-agent coordinator+helpers window stalling (31 directed broadcasts, few decisions) while peer-pair sidebars resolved the same class of decision in minutes — logistics through a coordinator, design substance through a sidebar. Blocked-on-a-peer routes: bounded-deadline directed event with a named default action, brief poll, then owner escalation. Delegation goes by judgement load, not parallelism; work routes as offers with a costless decline ("the fleet is built to catch work, not seats"). Identity (PDR-027) is distinct from liveness (PDR-078, heartbeat recency — never computed from claim freshness). Threat model: trusted agents only; hostile-agent hardening is a category error routed to the owner.
- `AGENT.md` — entry point; names the two first-class seats (Director, Implementer per PDR-117) and mandates the `start-right-*` skills as the entry to all work.
- `user-collaboration.md` — the agent-to-owner half: owner signals express Practice intent; a specific owner instruction outranks a general standing practice; when owner directions cross, the owner may name a single final authority for the window (the founding instance was a named Director seat); agents classify risk, humans accept risk.
- `principles.md` — the Decision Lenses are "the shared decision substrate every agent and the Director apply, so decisions stay coherent across the team without escalation"; agent-work capabilities (collaboration, coordination, work management, direction, lifecycle, identity, claims, handoff, review routing) are Practice-owned by default.
- `continuity-practice.md`, `metacognition.md`, `orientation.md` — continuity surfaces and tiers, stance under correction ("run standard team moves by default"), and the layering/authority contract that locates every collaboration surface.

## 10. Cross-cutting themes (what the estate has concluded)

1. **Tripwires, not locks.** Agents are reasoning peers; claims surface coordination and never refuse entry; every coordination rule is knowledge-plus-dialogue, not a mechanical gate on peers.
2. **Two team topologies are canonical** — coordinator+helpers and peer-primary — with different cost shapes (protocol cost vs shared-resource contention). Below four agents, peer coordination beats a formal Director; the phase transition is in touching threads, not agent count; n=2 is a distinct reduced mode.
3. **Roles are leases over boundaries.** Pressure before role, boundary before identity; the role menu is memory support, not topology. The two first-class seats: Director (centralise the awareness, pure direction) and Implementer (isolate the doing, worktree per lane), with Marshal and Curator as composable lanes.
4. **Ownership partitioning beat coordination protocol** as the cure class that stuck: worktrees, explicit pathspecs, a single commit warden, a single coordination home for registry state.
5. **Liveness is hard and layered.** Every liveness signal built has been impersonated by a dead process; liveness is a partial order of classes (PDR-133), never claim freshness, and the only reliable verdict is work-evidence. Silence is never liveness; ping before escalate.
6. **Comms is first-class and multi-channel** — durable event stream (the record), ARC rapid channels (dialogue), s2s (unblocking) — with a mirroring obligation and an all-channels watcher as the first team-bootstrap move.
7. **Fleets are scientific instruments.** Tier-matched seeding, per-tier unseeded baselines, decoys, falsification arms that can return "sound", double blind reduction, committed walker-visible briefs, deterministic aggregation (LLMs judge atomically, code counts), calibration before scale, checkpoints between stages, and design review before expensive dispatch.
8. **The verify half carries the value.** ~80% of one fleet's verdicts were refutations; conserve-by-default because single-voter kills run ~80% false; anchor findings to verbatim quotes; measure independence rather than asserting it.
9. **Cost is turns × context, not model tier.** Least-privilege single-turn cells cut cost 7–17×; tier buys direction → severity → frame-judgement, in that order; budget estimates run ~2× under.
10. **Convergence is governed, not emergent.** Loop-gain checks, terminal-round criteria, partition rulings when rounds stop shrinking; a diverging review loop is a routing failure.
11. **Warrant before instrument.** Internal checks audit mechanics; only external reads (usually the owner) audit whose question is being answered; convergence of many agents on one frame proves transmissibility, not truth.
12. **Nothing relies on timing or races.** Per-seat directories, task ids echoed through output schemas, provenance that recomputes; unverifiable provenance is struck.
13. **Passive doctrine does not bind the next action.** Only structural interrupts at the action moment have traction — measured longitudinally, not anecdotal.
14. **Named open gaps**: shared-memory/provenance/conflict-resolution semantics across agents are weak everywhere (including the external landscape); human oversight primitives are shallow; fleet-record discoverability lags fleet production (the lane README indexes almost none of its fleet records). Two gaps named in the historical record are since cured by accepted doctrine: the executive-memory sink and the missing cross-plane meta-pattern scan both fell to PDR-028's executive-memory feedback loop and consolidation's cross-plane scan.
