# A Legitimate Principle Invoked as Cover for Not Doing the Work

The dangerous cousin of [`fluency-is-a-failure-vector`](fluency-is-a-failure-vector.md).
Fluency is a *smooth* justification you over-trust; this is a *true* justification
you over-extend. A real principle — conservation, owner-authority, proportionality,
restraint — is bent to license an omission it does not actually cover. Because the
cover is genuine doctrine, the move *feels* principled, which is exactly what stops
you noticing it is avoidance.

## Anti-pattern

The principle is real; the extension is false. The tell is a one-clause leap from a
true premise to a convenient omission:

- *"Don't chase the fitness number"* (true) → *"so I needn't investigate why it is
  high"* (false — the conservation invariant says fitness **routes** work; "don't
  chase" ≠ "don't investigate").
- *"That decision is owner-routed"* (true of a verdict) → *"so I needn't graduate
  the learned lessons into their home"* (false — homing settled lessons IS
  consolidation; an owner-gated *decision*'s gating must not bleed onto a
  *graduation*).
- *"Don't over-reach / surface owner decisions"* (true) → *"so I should ask
  permission to do my own job"* (false — doing the assigned consolidation work is
  not over-reach).

The deeper instance: reaching for **"this is an emergent / inherent system
property"** to explain a failure, when a cheap concrete instruction or guardrail
fix exists. "Systems are complex" absolves both the instruction and the agent of a
fixable defect — systematising a gap into inevitability is itself this pattern.

## The cure

At the moment a principle is your reason for **not** doing something, run the test:
**does the principle actually license this omission, or am I bending it?** State the
principle's real scope and the omission side by side — the gap is usually visible
immediately (`don't chase` governs *trimming-to-green*, not *reading*; `owner-routed`
governs *decisions*, not *homings*). When diagnosing a failure, **bias toward "is
there a concrete instruction/guardrail fix?" before concluding "emergent."** The
structural backing for this pattern is the consolidation read-gate and
graduation-non-deferrable clauses in
[`consolidate-docs`](../../../skills/knowledge/consolidate-docs/SKILL-CANONICAL.md) and
[`consolidate-until-done`](../../../skills/knowledge/consolidate-until-done/SKILL-CANONICAL.md)
— the firing gates, since naming the pattern does not inoculate against it
(`passive-guidance-loses-to-artefact-gravity`).
