> **POLARITY: PATTERN.** "Does it work?" has no answer until you name
> what KIND of thing it is. Each kind has its own success criterion.

## The shape

- **Name the kind first**: a tool you invoke, a tripwire that must
  auto-fire, a rule, a reference. Then apply *that kind's* criterion.
  Judging an invocable tool by "does it fire unprompted" (a tripwire's
  bar) is a category error — the tool's bar is "does it deliver when
  invoked".
- **Doubt is a possession too.** Guard against over-defending a position
  because it is *yours* — equally when you built the thing and when you
  are its loudest critic. Name the falsifier out loud either way.

## The cure

Before scoring a capability, write down its kind and the matching
criterion; before defending or attacking it, state what would prove you
wrong. Sibling: [`feedback_ground_convenient_claims`],
[`feedback_metacognition_impact_test`].
