> **POLARITY: PATTERN.** When a surface can't import your code, the
> repo's answer is *compile and bundle to a self-contained artefact* —
> the same answer it gives everywhere else.

## The shape

"The target can't import repo code" is a **build requirement** — emit a
self-contained artefact from the one canonical source (bundle, codegen,
inline-at-build with validation) — never a licence to hand-author a parallel
copy. Hand-copies breed a drift ecosystem: mirrors, pasted blocks, hand
schemas, and a re-diff checklist that only ever pins the blocks someone
remembered to list. Mirrors drift wherever they are not machine-held —
including the "source of truth" itself (the copy that actually ran can be
newer than the nominal source).

**The tell:** the moment a surface feels "special" enough to exempt from
TypeScript / DRY / strictness / schema-first, that feeling IS the cowpath
signal — the standards exist precisely for the surfaces that feel special.

**The cure that ends the class** is structural: one source, compiled or
bundled into the constrained artefact by the build, with schema validation at
the boundary. Discipline-level cures (re-diff checklists, conformance tests
on remembered blocks) only shrink the class and silently miss the unlisted
member. Sibling: the metacognition directive §Cure Shape (make the copy
generated by the implementation); `enforce-via-schema-not-prose-for-vendor-surfaces`.
